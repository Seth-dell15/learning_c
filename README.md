Ce projet à été créer pour apprendre les bases du C.
Ce projet suit une suite d'exercices du livre : "Le langage C" de B.W KERNIGHAN et D.M RITCHIE

Le dossier test correspond à mes tentatives d'apprentissages avant d'avoir touché au livre.
Tandis que le dossier chapter1 correspond au début du livre.

J'ai pour objectif de me servir de ce livre afin d'obtenir une meilleur compréhension des systèmes et pouvoir l'utiliser
afin de développer sur systèmes embarqués critique.
Au fur et à mesure du projet, j'espère apprendre et m'améliorer sur les algorithmes de data structures (DSA) et créer 
des programmes optimisés. 

Petite précision :

pour compiler : 

gcc nom_du_fichier.c -o nom_de_executable_choisi

puis pour exécuter :

.\nom_de_executable_choisi

Pour un fichier contenant un EOF, pour ne pas casser le programme, si vous êtes
sur CLion ou terminal windows exécuter la combinaison de touche suivant dans l'ordre :

entrée 

ctrl + z
